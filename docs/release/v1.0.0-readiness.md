# v1.0.0 readiness

What stands between today's master and a v1.0.0 candidate, requirement by requirement. It is a gate record, not a
release: it creates no tag, no release and no Marketplace listing, and it says **not ready** until every row is *met* or
carries an accepted disposition. The statements in [the draft notes](v1.0.0-notes-draft.md) may only use what is *met* here.

**As of** master `109bc6a` (2026-10-08), the v1.0.0 candidate. Update the SHA when you update a row.

Words: **met** (built, tested, evidence named), **accepted** (the owner accepted a stated limit; quoted in the notes),
**pending** (not met, and the owner has not accepted leaving it), **owner** (only the owner can do the step).
