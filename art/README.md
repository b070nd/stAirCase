# Liminal Circuits

Algorithmic philosophy of defended boundaries.

## Files

| File | Description |
|------|-------------|
| `liminal-circuits.md` | Algorithmic philosophy — the computational aesthetic manifesto |
| `liminal-circuits.html` | Interactive p5.js viewer — open in any browser, works offline |
| `vendor/p5.min.js` | Vendored p5.js 1.7.0 — no CDN dependency |

## Viewing

```bash
open art/liminal-circuits.html   # macOS
xdg-open art/liminal-circuits.html  # Linux
```

No server required. Fully offline and local-only — no CDN calls, no font
requests, no network traffic of any kind after `vendor/p5.min.js` is vendored.
Open the HTML file directly from disk; no build step, no runtime dependencies.

## Controls

| Control | Action |
|---------|--------|
| **Space / P** | Pause / resume animation |
| **S** | Step one frame (when paused) |
| Seed nav | Explore different defense topologies |
| Permeability | Low → dense rejection lattice · High → filled interior |
| Defense Layers | 2 = dramatic polarity · 5 = fine-grained gradient |
| ⎘ Copy Permalink | Share exact seed + parameter state via URL hash |
| ↓ PNG | Save current canvas as PNG |

## Concept

The piece encodes the same conceptual DNA as stAirCase itself: concentric enforcement layers, forensic records of what was denied, and a trust gradient earned only by surviving the full gauntlet. Same seed → identical defense topology. Different seed → wholly different system character.
